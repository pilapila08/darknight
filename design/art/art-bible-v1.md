## 0. 摘要（TL;DR）

- **一句话定位**：暗夜中的硬核像素 Roguelite——以 Brotato（"土豆兄弟"）式浓黑描边 + 精准打击感为骨，用 5 个氛围鲜明的小主题地图与 4 个 boss 级怪物，谱写一段暗黑孤胆求生的视觉短篇。
- **三大视觉锚点**：① 浓黑卡通描边（土豆兄弟式统一外轮廓）+ ② 暗黑底色 + 高饱和高光（"暗夜中的色彩"反差）+ ③ 5 张地图的色调"色环接力"（冷灰蓝 → 阴绿 → 暗紫 → 锈棕 → 深紫）。
- **核心短板（必须先补）**：P0 = `charger.png` / `elite.png` 实质为占位或错图（无视觉叙事）；`entities/player.py` 反向依赖 `ui/render_helpers.py`（技术债，会阻断 sprite 升级）。
- **可售卖基线**：UI 体系、HUD、选卡、血条、开始/结算界面、5 张地图的色调节奏、打击感系统已达独立游戏买断制的中端基线；角色/怪物 sprite 处于"勉强可玩但尚未商业化"的临界。

## 1. 视觉身份定位

### 1.1 风格参照（参考）
- **首要锚点**：Brotato / 土豆兄弟 —— 浓黑描边、卡通风、扁平像素、动效反作用力强。
- **次要锚点**：Vampire Survivors（同品类参考，但本项目要更"暗"、更"形"——用描边和形状感代替写实纹理）。
- **配色氛围参考**：Darkest Dungeon 的"暗黑中的局部高光"（不要写实、不要血腥，保留卡通风的轻盈）。

### 1.2 三个核心视觉锚点（必须贯穿所有新资产）

| 锚点 | 含义 | 现有实现 | 资产规范 |
|---|---|---|---|
| ① 浓黑描边 | 所有世界实体（角色/怪物/boss/掉落物）外缘必须有可识别的深色外轮廓 | ✅ `OUTLINE_COLOR=(18,14,26)` 厚度 2px | 所有精灵 base 网格必须预留 1-2px 透明外缘用于描边渲染 |
| ② 暗夜反差 | 底色暗、冷（≤40 平均亮度），高光高饱和（≥70% 饱和度） | ✅ `AMBIENT_BY_MAP` 5 色 + 乘法暗角 | UI 文本/图标在任何地图底色上对比度 ≥ 4.5:1（WCAG AA） |
| ③ 色环接力 | 5 张地图以"灰蓝 → 阴绿 → 暗紫 → 锈棕 → 深紫"递进 | ✅ `MAP_CONFIGS[].accent_color` 数值与命名一致 | 地图主题色 = accent_color 出现在：① 边界描边 ② 散布景物（点缀/草丛/碎石）③ HUD 在该地图的高亮色 |

### 1.3 不做什么（视觉红线）❌
- ❌ 写实像素（不要模仿 16-bit SNES RPG 的写实纹理）。
- ❌ 高饱和底色（暗夜基调被破坏）。
- ❌ 抛弃描边直接用半透明蒙版（会出现"融入背景"的视觉塌陷）。
- ❌ 引入 3D 资产或高分辨率写实元素（破坏像素一致感）。

## 3. 像素规格规范

### 3.1 角色与世界实体

| 类别 | 源网格（base） | 渲染尺寸（屏幕） | 帧数 | 描边预留 |
|---|---|---|---|---|
| 玩家 | 16×16 | **32×32** | 3 帧（待机呼吸/移动摆动） | 1px 透明外缘 → 应用 2px OUTLINE_COLOR |
| 普通敌人 | 16×16 | **28×28** | 3 帧（上下浮动 wobble） | 同上 |
| 精英怪 | 16×16 | **40×40** | 3 帧（更大 wobble + 抖动） | 同上 |
| Boss | 96×96 | **60-100px（按设定）** | 3 帧 | 同上 |
| 子弹 | 编程生成 | radius 5（玩家）/ 4（敌方） | 单帧 | 不需要 |
| 经验球 nova_orb | 8×8 | 24×24 | 单帧 | 1px |
| 血包 health_pack | 8×8 | 24×24 | 单帧 | 1px |
| 护盾 shield_pickup | 8×8 | 24×24 | 单帧 | 1px |

> ⚠️ **任务描述与素材事实偏差**：`player.png` 实际为 48×16（3 帧 × 16px），并非 96×32。所有小怪 48×16。所有 Boss 288×96（3 帧 × 96px）。所有 pickup 24×24（非动画）。
> ✅ 源网格已经在 `effects/asset_loader.py:load_image()` 的 `fw = img.get_width() // 3` 处被 loader 自动按"宽除以 3"切成 3 帧。

### 3.2 帧动画原则
- **3 帧约束**：现有 loader 强约束为 3 帧横向 sprite sheet。所有新角色也必须以 3 帧提交，否则 loader 静默退化为程序化像素图。
- **动画风格**：第二帧一般为"动作极点"（如武器挥下、跃起中点），第三帧与第一帧相同或镜像——保持"土豆兄弟式乒乓"。
- **节奏**：玩家 0.1s/帧，敌人 0.15s/帧（详见 `entities/animation.py`）。

### 3.3 特殊效果规格

| 类别 | 规格 |
|---|---|
| 子弹发光 | 圆形 + 内核高光（亮色 = 原色 +80）+ 拖尾（半透明小圆） |
| 经验球 | 主色圆形 + 高光（亮色 = 原色 +100，左上偏移 1px） |
| 受击闪白 | sprite 蒙版 → 全白剪影，0.1s 闪烁（基于 mask，最干净的反馈） |
| 死亡残影 | sprite 蒙版 → 全白剪影 → 1.55x 放大 + alpha 衰减 0.28s |
| 枪口火光 | 圆形 + 方向光刺，0.06s 单帧 |
| 低血量脉动 | 屏幕边缘红色渐变叠加，呼吸频率 ~6Hz |

## 4. UI 视觉规范

### 4.1 字体 ✅
- **首选**：在 `assets/fonts/` 放入 .ttf/.otf/.ttc 后自动加载（loader 自动选第一个）。🅢 建议优先：思源宋体 / Noto Serif CJK SC（衬线带"古卷"气质）或 Noto Sans CJK SC Bold（标题更现代）。
- **回退顺序**（loader 内置）：microsoft yahei → simhei → simsun → noto sans cjk sc → wenquanyi micro hei → arial unicode ms → ms gothic → 默认 None。
- **字号规范**：标题 64px（开始/结算）| 标题 32px（暂停/选卡）| 正文 18-20px | 说明 14-15px | tooltip 11-13px。

### 4.2 面板规范（卡片式 UI）

| 元素 | 规范 |
|---|---|
| 背景 | (20,23,33) 主底 + (12,14,20) 内凹区（如技能卡下次升级框） |
| 边宽 | 1px（弱提示）/ 2px（标准）/ 3px（悬停/激活） |
| 边色 | (78,88,112) 静态 / 稀有度色 悬停 / GOLD 关键按钮 |
| 圆角 | 6-10px |
| 顶部色条 | 6px 高，颜色 = 稀有度色（技能卡）/ 主按钮色（结算面板胜利/失败） |
| 阴影 | `pygame.Surface` 黑色 (0,0,0,110) 大一圈 16px，偏移 (-8,-3) |
| 悬停反馈 | 位置上移 8px + 边框加亮 + 稀有度 glow 脉动 |

### 4.3 技能图标 ✅（`ui/drawables.py` 中 13 种程序化 shape）
- **arrow_up / arrow_right / lightning / speed / triple / magnet / snowflake / crit / heart / blade / chain / trap / shield / coin**
- 颜色 = 主色 + glow（高光色）+ border（描边色），全部存于 `SKILL_ICONS`。
- 🅢 建议：未来若要做"技能专属插画图标"，应保持 32-44px 方形 + 厚描边 + 居中单色，与现有 shape 系统风格一致。

### 4.4 HUD 规范 ✅
- **HP/经验条**：圆角矩形，背景 (10,10,14) → 边框 (130,45,45) 低血 / (45,130,80) 正常 / (170,130,45) 经验金边。**延迟条**（ghost）白色缓慢缩短，是"刚掉了多少血"的视觉语言。
- **低血量脉动**：HP < 30% 时血条颜色 `(255, int(50+70*sin), int(50+40*sin))` 红色呼吸，叠加 `effects/juice.py` 的屏幕边缘红色 vignette。
- **Boss 血条**：屏幕顶部居中，宽度 400px，登场 0.8s 展开动画 + 延迟条，< 30% HP 时变红。
- **时间显示**：右上角，独立背景框避免与 FPS 重叠。

### 4.5 暂停 / 开始 / 结算
- **开始界面**：垂直渐变（深紫→近黑）+ 上浮暗紫光点粒子 + 标题呼吸光晕（金色 + 阴影 + 4 方向偏移 glow）+ 金色"开始游戏"按钮 + 呼吸边框。
- **暂停菜单**：中央 340×270 面板，两按钮（继续/退出），金色悬停。
- **结算面板**：500×360 中央面板，胜利绿边 / 失败红边，行依次浮现 + 数字滚动（0.5s ease-out-cubic 滚到目标），新纪录呼吸金光 ★。

## 5. 光照与氛围规范

### 5.1 全局光照（乘法混合暗角）✅
- **算法**：darkness 表面先填 `ambient`（地图色调）→ 加法叠加光源径向渐变 → 整张 `BLEND_RGB_MULT` 叠加到画面。
- **光源上限**：96 个/帧（避免性能塌陷）。
- **光源颜色**：可指定任意 RGB，叠加在环境色上形成"色温反差"。
- **缓存**：按 (size_step, color) 缓存贴图，>64 项清空。

### 5.2 氛围层级（叠加顺序，从下到上）
1. **背景**：地图棋盘格纹理（bg/grid/edge 3 色 + 斑点）
2. **地图机制**：毒池 / 黑暗浪潮 / 废墟方块 / 引力异常（纯色 + alpha）
3. **散布景物**：speck（暗点缀）/ tuft（草丛）/ stone（碎石带高光）
4. **世界实体**：玩家 + 敌人 + Boss + 掉落物 + 子弹
5. **特效（juice）**：死亡残影 / 火花 / 枪口火光
6. **光照**：darkness 表面整张 BLEND_RGB_MULT（压暗 + 加亮）
7. **屏幕特效**：全屏闪光 / 低血量脉动
8. **UI**：HUD / 暂停 / 选卡 / 开始 / 结算

### 5.3 主题色规则（重要约束）✅
- **每张地图只能有 1 个主色（accent_color）**：散景点缀 / 草丛 / 边界描边 / 光源 tint 都用这一色或衍生色。
- **光源 tint** 🅢 建议：玩家光源 = (255, 220, 150) 暖白（"我活着"）；敌人光源 = 各自 boss/enemy 主题色（如尸王 (40,80,20)、暗影 (100,0,150)）。

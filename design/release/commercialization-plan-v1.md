## 0. 一句话结论

**推荐路径：itch.io 首发（1 个月内）→ 英文本地化 + Steam 页面上线（第 5-8 周）→ Steam 正式发售（验证后）。**

## 1. 平台对比分析：itch.io vs Steam

### 1.1 事实基准

| 维度 | itch.io | Steam（Steam Direct） |
|------|---------|----------------------|
| 上架成本 | 免费，平台抽成 10%（可设 0%，默认 10%） | **一次性 $100 / 款**（Steam Direct 费，累计毛利 $1000 后可退回） |
| 收入分成 | 默认 10%（可自行调低） | 30%（毛利超 $10M 降至 25%，超 $50M 降至 20%） |
| 审核难度 | 无审核队列，上传即上架 | Direct 制无排队审批，但有"质量线"抽查；纯 pygame 中文 UI 可能被质疑 |
| 支付支持 | PayPal + 本地支付；对中文买家支持支付宝/微信支付（【假设】以 itch 当前支付政策为准，上架前需实测） | Steam 钱包 + 全球支付；**国区定价用 CNY**，玩家支付习惯成熟 |
| 流量/发现 | 中等，靠标签、合集、游戏节（jam）；独立玩家浓度高 | 极高，靠愿望单、评测、推荐算法、促销 |
| 演示/试玩 | 极简：可设免费版/付费版/PWYW，demo 即一个免费页 | 支持 Demo 构建，愿望单转化是核心 KPI |
| 版本/热修 | 直接替换文件，秒级生效 | SteamPipe 上传 + 审核窗口（通常小时级） |
| 平台适配压力 | 低，只要 Windows 包即可 | 玩家期望更高：手柄、成就、云存档、Steamworks 集成 |
| 对中文作者友好度 | 高（中文支付 + 无门槛 + 社区宽容） | 中（$100 + 英文门槛 + 质量线） |

### 1.2 分析

**itch.io 是"验证 + 冷启动"平台，Steam 是"放大 + 变现天花板"平台。**

对本项目（单人开发、纯 pygame、中文 UI、无营销预算、内容量中等）：
- itch.io：零成本、秒上架、中文买家可支付、社区对独立小游戏宽容，适合**先发 demo 验证玩法吸引力与定价容忍度**。
- Steam：$100 + 英文本地化 + 更高的完成度预期 + Steamworks（成就/云存档为加分项，非硬性）。**中文独占 UI 在 Steam 全球市场会显著压缩销量**，必须先做英文。

### 1.3 推荐

> **推荐：itch.io 首发（第 1-4 周）→ Steam 第二阶段（第 5-8 周起）。**
>
> 理由：
> 1. itch.io 无沉没成本，先验证"玩法和定价是否有人买单"；
> 2. 中文作者 + 中文玩家盘在 itch 上支付无障碍，可先吃中文社区；
> 3. Steam 的 $100 与英文成本，应在 demo/首发数据支撑后再投入；
> 4. itch.io 上获得的截图/GIF/玩家反馈，可直接复用于 Steam 商店页。

## 2. 定价建议

### 2.1 定价逻辑

内容量评估（【事实】）：
- 单局上限 10 分钟（600s），5 张地图、4 个 Boss、12 个技能、5 类敌人；
- 核心循环 = 刷怪升级 + Boss 战 + 分数挑战；内容深度属"中短程 roguelite"。
- 同类参照：Vampire Survivors 首发 $2.99（后提价 $4.99）；Brotato $4.99；itch.io 上同类多数 $2-5。

结论：**落在 $2-5 区间中低位 $2.99**，是"冲动购买"甜蜜点；$1.99 会低估价值且对销量提升有限，$4.99 对无名作者 + 中文 UI 偏高。

### 2.2 建议价与区域定价表

| 区域 | itch.io 显示价 | Steam 建议价（第二阶段） | 说明 |
|------|---------------|--------------------------|------|
| 美国 | $2.99 | $2.99 | 基准价 |
| 中国大陆 | ~¥21（按 $2.99 汇率折算） | **¥9-12** | Steam 国区按 Valve 建议区间，约为美区 35-40%（【假设】参考 Valve 区域定价指南与同类 indie 惯例） |
| 欧洲 | €2.99-3.29 | €2.99 | 含增值税 |
| 日本 | ¥400 左右 | ¥350-400 | |
| 韩国 | ₩4,500 左右 | ₩4,500-5,000 | |
| 英国 | £2.49-2.79 | £2.49 | |

### 2.3 促销与首发策略

- 首发 7 天 **-20%**（itch 售价 $2.39 / Steam 折后 ¥7-10）。
- itch.io 可开启 **PWYW（pay-what-you-want）**：设 $2.99 为建议价 + 最低 $1.99，扩大购买面（【假设】PWYW 可提升转化，需 A/B 观察）。
- 观察指标：首周转化率、退款率、评论区定价反馈；若 demo 口碑好、内容扩充后，可在 Steam 阶段提价到 $3.99。

## 5. 本地化范围建议

### 5.1 现状（【事实】）

- 全部 UI 为硬编码中文，无 i18n 框架；约 400 行中文分布：ui/（start_screen 32、skill_select 19、hud 15、game_over 16、skill_bar 21、test_panel 100、drawables 17 等）、skills.py（134）、settings.py（24）、main.py（16）。
- **利好**：地图配置已含 `name_en` 字段（Bleak Graveyard / Corrupted Swamp / Shadow Court / Iron Ruins / Void Rift），说明数据层已预留英文，可作为本地化起点。

### 5.2 建议与优先级

| 阶段 | 语言 | 优先级 | 理由 |
|------|------|--------|------|
| itch.io 首发 | 中文 | **P0** | 作者为中文作者，首发目标为中文玩家盘 |
| itch.io 首发 | 英文 | P1（可不做，但建议同步抽字符串） | itch 有全球独立玩家，英文可扩量；但首发可先中文 |
| Steam 阶段 | 英文 | **P0（硬门槛）** | 中文独占在 Steam 全球市场显著受限 |

**落地建议**：
- 首发不做全量本地化框架；**但立即启动字符串抽取**（把硬编码中文收敛到 `i18n/strings.py` 单表），为英文铺路——这是代码改动，交程基岩。
- 规模预估：约 200-300 条唯一字符串；英文翻译可由作者 + AI 辅助完成，成本低。
- Steam 前完成：内置中文字体 + 英文 UI 全量。

  ├─ 商店页（标题/短描述/标签/素材）

  ├─ 观察转化率/退款/评论
  └─ 收集反馈 → 决定是否提价 $3.99

第 5-6 周  Steam 准备
  ├─ 英文 UI 全量 + 内置字体（程基岩 + 本地化）
  ├─ Steam Direct 申请（$100）
  └─ Steam 商店页 + 愿望单页面上线

第 7-8 周  Steam 发售 + 迭代
  ├─ Steam 正式发售（建议配合促销节）

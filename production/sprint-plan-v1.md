## 0. 一句话结论

**游戏离"可售卖"只差一层"发布硬化"：玩法层有 3 个 P0 代码断裂（胜利判定缺失 / 死亡卡 ESC / 经验球死代码），资产层有 2 个 P0 素材问题（精英怪空白 / 冲锋怪错图），叠加技术硬化（存档/字体/版本）即可进入 itch 首发。预计 8 周走完 首发 → Steam 发售。**

## 4. 冲刺排期（Steam 直上版，6-8 周）

```
第 1 周  P0 玩法修复：胜利判定(R1) + ESC 返回(R2) + 经验球死代码清理(R2)
         P0 素材修复：elite / charger 精灵表重绘
第 2 周  P0 技术硬化：存档路径 / 内置字体 / 版本 1.0 / 杀软检查
         字符串抽取 + 英文本地化启动（Steam 硬门槛，提前）
         商店素材产出（Steam 主图/截图/GIF/图标）
第 3 周  Steam Direct 申请（$100 已批）+ 商店页/愿望单上线
         itch 免费 Demo 同步上线（引流 + 数据验证）
第 4 周  英文 UI 收尾 + 冒烟测试全绿 + 内容补丁第 1 弹（角色解锁最小版）
第 5-6 周 Steam 正式发售 + 首周运营（补丁/评论响应）
并行线：R3 数值基准 → R4 难度曲线 → R5 角色解锁设计（第 2-4 周穿插）
```

**里程碑门控**：
- Steam 发售 go：P0-A~F 全绿 + 英文完成 + 冒烟测试通过
- 内容补丁 go：角色解锁设计评审通过

## 5. 已知风险与缓解

| 风险 | 等级 | 缓解 |
|------|------|------|
| 曝光不足（单人无预算） | 高 | 免费 demo + B 站开发日志 + itch 标签/游戏节 |
| P0 修复引入回归（胜利/ESC 是核心路径） | 中 | 复用 `_smoke_test.py` 扩展冒烟用例，修复后跑全量 |
| 双线并行疲劳（工程单点） | 中 | P0 修复集中在第 1-2 周，之后工程转 Steam 准备 |
| 内容量不足（10 分钟上限） | 中高 | $2.99 定价 + meta/内容补丁路线兜底 |
| 中文 UI 限全球 | 中 | 英文为 Steam 硬门槛，字符串抽取尽早 |

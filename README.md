# 暗夜求生 (Darknight Survival)

类《吸血鬼幸存者》的俯视角自动射击 Roguelite 游戏。在黑夜中生存，击杀敌人，拾取经验，升级强化，挑战最高分。

## 版本更新记录

### v3.4 (2026-06-18) - 升级节奏放缓 + 技能数值再平衡

**升级节奏调整：**
- `settings.py` 中 `XP_BASE` 从 8 提升到 14，前期升级不再过于密集。
- `XP_GROWTH` 从 1.10 提升到 1.15，中后期等级需求增长更明显。
- 普通模式和测试模式的升级奖励从 `max_hp +2 / hp +3` 调整为 `max_hp +1 / hp +1`。
- 升级仍然保留稳定正反馈，但不再同时提供过强的免费生存成长。

**经验倍率调整：**
- `贪婪之魂` 从 `1.25^次数` 的乘法叠加改为 `1 + 0.15 × 次数` 的线性叠加。
- 普通怪、精英怪和 Boss 奖励经验都使用新的线性贪婪倍率。
- 测试模式的经验倍率控制仍然保留，并在新公式之后继续生效。

**技能数值调整：**
- `急速射击` 从攻击间隔 `-25%` 调整为 `-15%`，并新增最低间隔 `0.18s`。
- `致命节奏` 从 `+15% 暴击率 / +0.5 暴击伤害` 调整为 `+10% / +0.25`，暴击率最高 60%。
- `急速子弹` 达到速度上限后不再转化为额外伤害倍率，并会从随机升级选项中过滤。
- `旋转利刃` 初始伤害从 10 调整为 8，重复选择从 `+2伤害` 调整为 `+1伤害`。
- `连锁闪电` 初始弹跳从 8 次调整为 5 次，初始伤害从 8 调整为 7，重复选择从 `+2伤害` 调整为 `+1伤害`。
- `剧毒地雷` 范围叠加从 `+0.1` 调整为 `+0.05`，释放间隔最低限制为 `1.2s`。
- 升级选项说明和悬停详情同步更新，避免界面显示旧数值。

## 游戏机制

### 核心循环
击败敌人 → 直接获得经验 → 升级 → 三选一强化 → 变强 → 面对更强的敌人

### 游戏时长
- 游戏时长上限：**10 分钟（600秒）**
- 存活满10分钟即为胜利
- 右上角显示当前存活时间（MM:SS）

### 武器系统（通过升级逐步解锁）

| 武器 | 效果 | 叠加 |
|------|------|------|
| 自动枪 | 自动瞄准并射击最近敌人（基础伤害 2） | 弹量、伤害、射速 |
| 暗影新星 | 周期性释放范围冲击波，初始伤害 12，半径 150 | 重复 +伤害、+范围、缩短冷却 |
| 连锁闪电 | 初始 5 次弹跳，伤害 7 | 重复 +1 弹跳，+1 伤害 |
| 剧毒地雷 | 自动释放毒圈（12 秒持续，4/s 伤害）| 重复 -0.1s 间隔至最低 1.2s，+0.5 伤害，+0.05 范围 |

| 凌波微步 | 移动速度 +25% | 乘法 |
| 增加弹量 | 每次射击 +1 发子弹 | 线性 |
| 贪婪之魂 | 经验获取 +15% | 线性叠加 |

| 复苏之风 | 每 20 击杀回复 1 HP（可叠加）| 一次 |
| 钢铁意志 | 受伤 -10% | 重复乘算 |
| 暗影新星 | 周期性范围爆发（伤害并击退周围敌人）| 可叠加 |
| 连锁闪电 | 弹跳闪电（打击多个敌人）| 可叠加 |
| 剧毒地雷 | 自动释放毒圈 | 可叠加 |

### 每次升级效果
- 血量上限 +1
- 当前血量 +1（不超过血量上限）

### 敌人种类

| 敌人 | 特点 | 解锁时间 |
|------|------|----------|
| 基础怪 | 向你走来 | 0 秒 |
| 冲锋者 | 每隔几秒向你冲刺 | 25 秒 |
| 远程怪 | 保持距离向你射击 | 50 秒 |
| 自爆虫 | 高速冲撞，死亡范围爆炸 | 75 秒 |
| 精英怪 | 更大更硬，金色头冠 | 90 秒 |

### 动态难度

**每 25 秒（怪物成长）：**
- 怪物血量/伤害增加（等差数列：+1, +2, +3...）
- 刷新间隔加速（二次函数增长）

**每 50 秒（经验加成）：**
- 经验获取 +0.5（平滑增长）

**难度等级对照表（怪物血量/伤害）：**

| 时间 | 成长次数 | 总增量 | 怪物HP | 怪物DMG | 刷新间隔 |
|------|----------|--------|--------|--------|----------|
| 0s | 0 | 0 | 1 | 1 | 0.47s |
| 25s | 1 | 1 | 2 | 2 | 0.23s |
| 50s | 2 | 3 | 4 | 4 | 0.12s |
| 75s | 3 | 6 | 7 | 7 | 0.07s |
| 100s | 4 | 10 | 11 | 11 | 0.05s |
| 150s | 6 | 21 | 22 | 22 | 0.03s |

## 自定义素材

### 替换图像
将 `.png` 文件放入 `assets/sprites/`（删除还原默认）：

| 文件名 | 尺寸 | 格式 |
|--------|------|------|
| `player.png` | 96×32 (3帧×32) | PNG，横向 3 帧精灵表 |
| `enemy.png` | 84×28 | 同上 |
| `elite.png` | 120×40 | 同上 |
| `charger.png` | 84×28 | 同上 |
| `ranger.png` | 84×28 | 同上 |
| `exploder.png` | 84×28 | 同上 |

> 精灵表：3 张等宽帧横向排列，程序自动切割并缩放到目标尺寸。

### 音效说明
当前音效与背景循环由 `systems/audio_manager.py` 使用标准库合成生成，不依赖外部音频文件。

## 打包为 EXE

```bash
pip install pyinstaller
python build.py
```

或手动打包：
```bash
pyinstaller --onefile --windowed --name "Darknight" main.py
```

输出：`dist/Darknight.exe`

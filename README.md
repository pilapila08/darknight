# 暗夜求生 (Darknight Survival)

类《吸血鬼幸存者》的俯视角自动射击 Roguelite 游戏。在黑夜中生存，击杀敌人，拾取经验，升级强化，挑战最高分。

## 操作说明

| 按键 | 功能 |
|------|------|
| `W` / `↑` | 向上移动 |
| `A` / `←` | 向左移动 |

## 游戏机制

### 核心循环
击败敌人 → 直接获得经验 → 升级 → 三选一强化 → 变强 → 面对更强的敌人

### 游戏时长
- 游戏时长上限：**10 分钟（600秒）**
- 存活满10分钟即为胜利
- 右上角显示当前存活时间（MM:SS）

### 武器系统（通过升级逐步解锁）

| 武器 | 效果 | 叠加 |
|------|------|------|
| 自动枪 | 自动瞄准并射击最近敌人（基础伤害 2） | 弹量、伤害、射速 |
| 旋转利刃 | 初始 3 个刀刃环绕，伤害 10 DPS | 重复 +1 刀，+2 伤害 |
| 连锁闪电 | 初始 8 次弹跳，伤害 8 | 重复 +1 弹跳，+2 伤害 |
| 剧毒地雷 | 自动释放毒圈（12 秒持续，4/s 伤害）| 重复 -0.1s 间隔，+0.5 伤害，×1.1 范围 |

### 成长技能

| 技能 | 效果 | 叠加 |
|------|------|------|
| 火力增强 | 子弹伤害等差数列增加 (1,1,2,2,3...) | 等差 |
| 急速射击 | 攻击间隔 -25% | 乘法 |
| 凌波微步 | 移动速度 +25% | 乘法 |
| 增加弹量 | 每次射击 +1 发子弹 | 线性 |
| 贪婪之魂 | 拾取范围 +50%，受伤 +10% | 乘法 |
| 致命节奏 | +15% 暴击率，+0.5 暴击伤害 | 可叠加 |
| 复苏之风 | 每 20 击杀回复 1 HP（可叠加）| 一次 |
| 钢铁意志 | 受伤 -10% | 重复乘算 |
| 旋转利刃 | 环绕刀刃（触敌即伤）| 可叠加 |
| 连锁闪电 | 弹跳闪电（打击多个敌人）| 可叠加 |
| 剧毒地雷 | 自动释放毒圈 | 可叠加 |

### 每次升级效果
- 血量上限 +1
- 当前血量 +1（不超过血量上限）

### 敌人种类

| 敌人 | 特点 | 解锁时间 |
|------|------|----------|
| 基础怪 | 向你走来 | 0 秒 |
| 冲锋者 | 每隔几秒向你冲刺 | 25 秒 |
| 远程怪 | 保持距离向你射击 | 50 秒 |
| 自爆虫 | 高速冲撞，死亡范围爆炸 | 75 秒 |
| 精英怪 | 更大更硬，金色头冠 | 90 秒 |

### 动态难度

**每 25 秒（怪物成长）：**
- 怪物血量/伤害增加（等差数列：+1, +2, +3...）
- 刷新间隔加速（二次函数增长）

**每 50 秒（经验加成）：**
- 经验获取 +0.5（平滑增长）

**难度等级对照表（怪物血量/伤害）：**

| 时间 | 成长次数 | 总增量 | 怪物HP | 怪物DMG | 刷新间隔 |
|------|----------|--------|--------|--------|----------|
| 0s | 0 | 0 | 1 | 1 | 0.47s |
| 25s | 1 | 1 | 2 | 2 | 0.23s |
| 50s | 2 | 3 | 4 | 4 | 0.12s |
| 75s | 3 | 6 | 7 | 7 | 0.07s |
| 100s | 4 | 10 | 11 | 11 | 0.05s |

## 自定义素材

### 替换图像
将 `.png` 文件放入 `assets/sprites/`（删除还原默认）：

| 文件名 | 尺寸 | 格式 |
|--------|------|------|
| `player.png` | 96×32 (3帧×32) | PNG，横向 3 帧精灵表 |
| `enemy.png` | 84×28 | 同上 |
| `elite.png` | 120×40 | 同上 |
| `charger.png` | 84×28 | 同上 |
| `ranger.png` | 84×28 | 同上 |
| `exploder.png` | 84×28 | 同上 |

> 精灵表：3 张等宽帧横向排列，程序自动切割并缩放到目标尺寸。

### 替换音效
将 `.wav` 文件放入 `assets/sounds/`（删除还原默认）：

| 文件名 | 说明 |
|--------|------|
| `shoot.wav` | 射击音（~40ms） |
| `death.wav` | 死亡音（~120ms） |

> 无需改代码——`asset_loader.py` 自动检测文件存在性。

## 打包为 EXE


或手动打包：
```bash
pyinstaller --onefile --windowed --name "Darknight" main.py
```
